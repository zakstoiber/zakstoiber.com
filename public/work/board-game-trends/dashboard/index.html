About the data

Every ranked game on BoardGameGeek (30+ user ratings) from an August 2026 pull, with its mechanism and category tags. Min. user ratings sets how many ratings a game needs to count everywhere on this page; 100+ is the default because a handful of ratings is noisy.

Trends run 1980–2025: 2026 is a partial year, and recent games are still collecting ratings. Games with no weight votes are left out of anything that uses weight. Rating is the average user rating, not BGG's adjusted geek rating.
